# CSE207 – Data Structures Lab (Java)

This repository contains Java implementations of fundamental Data Structures and Algorithms developed during the CSE207 Data Structures Lab course.

The goal of this repository is to strengthen my understanding of core data structures, improve problem-solving skills, and build a solid programming foundation using Java.

---

## Course Information

Course: CSE207 – Data Structures Lab  
Language: Java  
Focus: Data Structures and Algorithms Implementation  

---

## Topics Covered

### 1. Searching Algorithms
- Linear Search
- Binary Search

### 2. Sorting Algorithms
- Bubble Sort
- Selection Sort

### 3. Matrix Operations
- Matrix Addition
- Matrix Subtraction
- Matrix Multiplication
- Matrix Transpose

### 4. Doubly Linked List
- Insert at beginning
- Insert at end
- Insert at specific position
- Delete from beginning
- Delete from end
- Delete from specific position
- Traverse and display

### 5. Stack Operations
- Push
- Pop
- Peek
- Display elements

### 6. Stack Applications
- Infix to Postfix conversion
- Postfix expression evaluation

### 7. Queue Operations
- Linear Queue (Enqueue, Dequeue, Display)
- Circular Queue (Enqueue, Dequeue, Display)

### 8. Recursive Functions
- Factorial
- Fibonacci
- Reverse printing
- Palindrome check

### 9. Binary Search Tree (BST)
- Insert
- Delete
- Search
- Tree Traversals:
  - Inorder
  - Preorder
  - Postorder
  - Level Order

### 10. Graph Algorithms
- Breadth First Search (BFS)
- Depth First Search (DFS)
